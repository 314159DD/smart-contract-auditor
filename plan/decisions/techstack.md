# Tech Stack Decisions — Contract Auditor

## Decision Log

### 1. Slither as Solidity analysis foundation

**Decision:** Use Trail of Bits' Slither for AST parsing and base analysis
**Date:** 2026-03-24
**Status:** Accepted

**Context:** Need to parse Solidity source into an AST for analysis. Options: write custom parser, use py-solc-x, or use Slither.

**Rationale:**
- Slither is the industry standard (created by Trail of Bits, top audit firm)
- Handles import resolution, inheritance flattening, and multi-file contracts
- Built-in printers and detectors we can extend
- Active maintenance (last commit within days)
- Python-native — fits our stack

**Rejected alternatives:**
- py-solc-x: Only compiles, doesn't analyze. We'd need to build analysis from scratch.
- Custom ANTLR parser: Months of work to handle Solidity grammar edge cases.
- solc --ast: Raw AST output is hard to work with programmatically.

### 2. Claude API for AI analysis layer

**Decision:** Anthropic Claude (Sonnet) for vulnerability analysis and fix generation
**Date:** 2026-03-24
**Status:** Accepted

**Context:** The AI layer needs to understand Solidity code deeply, identify business logic issues, and generate specific code fixes.

**Rationale:**
- Claude excels at code analysis and reasoning
- Extended thinking helps with complex vulnerability chains
- Can generate before/after code diffs for fixes
- Already using across PPC projects (shared API key, consistent patterns)
- Cost: ~$0.003-0.01 per audit (Sonnet tier)

**Rejected alternatives:**
- GPT-5: Comparable but different API. Standardize on Claude.
- Aderyn MCP: Interesting tool but early stage. Use as supplementary, not primary.
- ChainGPT: Purpose-built for smart contracts but closed ecosystem.

---

### 3. FastAPI for backend (not Flask)

**Decision:** FastAPI over Flask for the API backend
**Date:** 2026-03-24
**Status:** Accepted

**Context:** Need an API that handles async audit processing, file uploads, and webhook handling.

**Rationale:**
- Native async support (audit processing is I/O bound: LLM calls, Etherscan API)
- Auto-generated OpenAPI docs (important for enterprise API tier)
- Built-in request validation with Pydantic
- BackgroundTasks for async audit processing
- Better performance than Flask for concurrent requests

**Why not Flask:**
- JobFlowAI uses Flask, but it's synchronous. Contract auditing needs async for LLM calls.
- FastAPI's BackgroundTasks are simpler than Flask + Celery.

### 7. Prominent liability disclaimer

**Decision:** Every report includes a legal disclaimer
**Date:** 2026-03-24
**Status:** Accepted

**Context:** Reality Check identified liability as the key risk. If we miss a vulnerability and funds are lost, we could face legal action.

**Rationale:**
- AI auditing catches 70-85% of vulnerabilities (not 100%)
- Reports clearly state: "AI-assisted analysis, not a replacement for manual audit"
- Recommend manual audit for contracts holding significant value
- Terms of Service limit liability to subscription fees paid
- No "certified safe" language anywhere

**Report disclaimer text:**
> This report was generated by automated static analysis and AI-assisted review. It is not a substitute for a comprehensive manual security audit. The authors assume no liability for undiscovered vulnerabilities. For contracts securing significant value, we recommend engaging a professional audit firm in addition to this analysis.
